### Отправка письма

1. используется сервис Resend (https://resend.com): 
    - зарегистрироваться;
    - создать API key;
    - скопировать API key.
2. в функции отправки письма (backend/utils.py -> send_reset_email(to_email, reset_link)):
    - использовать API key;
    - указать отправителя: onboarding@resend.dev;
    - указать получателя: to_email - почта, которая указана в БД у админа;
    - в письме передать reset_link - ссылку с токеном восстановления.
