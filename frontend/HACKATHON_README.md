# Хакатон 2025 - Сайт-лендинг

## Описание проекта

Современный лендинг-сайт для хакатона с полной функциональностью и адаптивным дизайном.

## Структура проекта

```
frontend/
├── public/                  # Статические файлы
├── src/
│   ├── components/
│   │   └── sections/       # Компоненты секций
│   │       ├── Header.js   # Навигация
│   │       ├── Hero.js     # Главный баннер
│   │       ├── About.js    # О мероприятии
│   │       ├── Statistics.js # Статистика
│   │       ├── Cases.js    # Кейсы для решения
│   │       ├── PhotoGallery.js # Фотоальбом
│   │       ├── Reviews.js  # Отзывы участников
│   │       ├── Consultation.js # Форма консультации
│   │       ├── News.js     # Новости
│   │       ├── FAQ.js      # Вопросы и ответы
│   │       └── Footer.js   # Подвал сайта
│   ├── pages/              # Страницы приложения
│   │   ├── Home.js         # Главная страница
│   │   ├── Registration.js # Регистрация
│   │   ├── Schedule.js     # Расписание
│   │   └── Rules.js        # Правила участия
│   ├── styles/             # Дополнительные стили
│   │   └── pages.css       # Стили для страниц
│   ├── App.js              # Главный компонент
│   ├── App.css             # Основные стили
│   └── index.js            # Точка входа
└── package.json            # Зависимости проекта
```

## Основные секции лендинга

### Главная страница включает:

1. **Header** - Навигационная панель с меню
2. **Hero** - Главный баннер с призывом к действию
3. **About** - Информация о мероприятии
4. **Statistics** - Статистика хакатона
5. **Cases** - Кейсы для решения участниками
6. **PhotoGallery** - Фотоальбом с прошлых мероприятий
7. **Reviews** - Отзывы участников
8. **Consultation** - Форма для получения консультации
9. **News** - Последние новости
10. **FAQ** - Часто задаваемые вопросы
11. **Footer** - Подвал с контактами и ссылками

### Дополнительные страницы:

- **Registration** - Подробная форма регистрации
- **Schedule** - Расписание мероприятия по дням
- **Rules** - Правила участия в хакатоне

## Технологии

- **React 19.1.1** - Основная библиотека
- **React Router DOM** - Роутинг между страницами
- **CSS Grid & Flexbox** - Современная верстка
- **Responsive Design** - Адаптивность для всех устройств

## Особенности

### Функциональность:
- Полностью адаптивный дизайн
- Интерактивные формы с валидацией
- Модальные окна для галереи
- Анимации и переходы
- FAQ с раскрывающимися ответами
- Якорные ссылки для навигации по секциям

### Дизайн:
- Современный градиентный дизайн
- Четкая типографика
- Консистентная цветовая схема
- Hover-эффекты и интерактивность
- Карточная верстка для контента

## Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm start

# Сборка для продакшена
npm run build
```

## Настройка

1. Замените placeholder изображения в папке `public/images/`
2. Обновите контактную информацию в компонентах
3. Добавьте реальные данные вместо моковых
4. Настройте отправку форм на бэкенд

## Развертывание

Проект готов для развертывания на любом хостинге, поддерживающем статические сайты:
- Netlify
- Vercel
- GitHub Pages
- Firebase Hosting

Все необходимые файлы будут созданы в папке `build/` после выполнения `npm run build`.
