### 1. Требования

- VPS-сервер с Ubuntu 22.04 или новее;
- зарегистрированный домен или поддомен;
- доступ к серверу по SSH;
- права на настройку DNS домена.

### 2. Настройка домена

У регистратора домена необходимо создать A-запись, которая будет указывать на IP-адрес сервера:
> Тип     Имя             Значение

> A         hackathon   123.123.123.123

### 3. Подключение к серверу по SSH

- ssh root@123.123.123.123;
- или использовать программу: PuTTY, SmartTTY или MobaXterm.

### 4. После подключения к серверу выполнить:

```bash
sudo apt update
sudo apt install docker.io docker-compose-v2 -y
sudo systemctl enable docker
sudo systemctl start docker
docker --version
docker compose version
```

### 5. Загрузка проекта на сервер

```bash
git clone git@github.com:gudvill/hakaton_uisi.git # клонировать репозиторий
``` 

### 6. В корне проекта необходимо создать файл .env с нужным содержимым

### 7. Запуск проекта
```bash
cd путь_к_проекту # перейти в папку проекта
sudo docker-compose up --build -d # собрать и запустить контейнеры
sudo docker ps # проверка контейнеров
sudo docker-compose down # остановить контейнеры (перед пересборкой после внесения изменений в проект)
```

### 8. Проверка работы

- Главная: http://hackathon.ваш-домен.ru
- API: http://hackathon.ваш-домен.ru/api/health
- Административная панель: http://hackathon.ваш-домен.ru/admin  

### 9. Настройка HTTPS (SSL)

Перед получением SSL открыть файл `nginx.conf` и добавить
```nginx
server {
	listen 80;
	server_name hackathon.ваш-домен.ru;
```

После этого выполнить:
``` bash
docker compose restart nginx

sudo apt update
sudo apt install certbot python3-certbot-nginx -y # установить Certbot
sudo certbot --nginx # получить сертификат
```

Certbot автоматически: выпустит бесплатный SSL-сертификат Let's Encrypt, настроит конфигурацию Nginx, включит HTTPS, настроит автоматическое продление сертификата.

В файле docker-compose.yml нужно сделать:
```yml
nginx:
  ports:
    - "80:80"
    - "443:443"
```

### 11. Обновление проекта (если получена новая версия сайта)

```bash
cd путь_к_проекту
git pull # подтянуть обновления из GitHub на сервер
sudo docker-compose down # остановить контейнеры (перед пересборкой после внесения изменений в проект)
sudo docker-compose up --build -d # собрать и запустить контейнеры
```

### 12. Важная информация
- домен или поддомен настраивается у регистратора домена и должен указывать на IP-адрес сервера;
- вносить изменения в исходный код проекта при смене домена не требуется;
- до получения SSL сайт будет работать по протоколу HTTP;
- после настройки Certbot сайт автоматически перейдёт на HTTPS;
- административная панель всегда доступна по адресу https://ваш-домен/admin.
