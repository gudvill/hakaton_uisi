## Веб-аналитика

1. используется сервис Яндекс Метрика:
    - создать счётчик на сайт;
    - получить счётчик ID (YANDEX_METRIKA_COUNTER_ID);
    - получить токен обращения к API (YANDEX_METRIKA_TOKEN).
2. в файле frontend/public/index.html:
    - вставить код счётчика перед тегом ```<head></head>```:
    ```html
    <!-- Yandex.Metrika counter -->
    <script type="text/javascript">
        (function(m,e,t,r,i,k,a){
            m[i]=m[i]||function(){(m[i].a=m[i].a||[]).push(arguments)};
            m[i].l=1*new Date();
            for (var j = 0; j < document.scripts.length; j++) {if (document.scripts[j].src === r) { return; }}
            k=e.createElement(t),a=e.getElementsByTagName(t)[0],k.async=1,k.src=r,a.parentNode.insertBefore(k,a)
        })(window, document,'script','https://mc.yandex.ru/metrika/tag.js?id=109326806', 'ym');

        ym(YANDEX_METRIKA_COUNTER_ID, 'init', {ssr:true, webvisor:true, clickmap:true, ecommerce:"dataLayer", referrer: document.referrer, url: location.href, accurateTrackBounce:true, trackLinks:true});
    </script>
    <noscript>
        <div><img src="https://mc.yandex.ru/watch/YANDEX_METRIKA_COUNTER_ID" style="position:absolute; left:-9999px;" alt="" /></div>
    </noscript>
    <!-- /Yandex.Metrika counter -->
    ```
    - заменить YANDEX_METRIKA_COUNTER_ID на реальное значение ID счётчика.
3. в файле backend/utils.py:
    - функция обращения к API (_fetch_metrika(key, params)) используется в сборе метрик;
    - использовать счётчик ID (YANDEX_METRIKA_COUNTER_ID) и токен обращения к API (YANDEX_METRIKA_TOKEN);
    - метрики: общая статистика, посещения, просмотры страниц, среднее время визита, глубина просмотра, популярные страницы, устройства, источники трафика.
4. вывод метрик происходит в файле Stats.js.

## Почтовый сервис

1. используется сервис Resend (https://resend.com): 
    - зарегистрироваться;
    - создать API key;
    - скопировать API key.
2. в функции отправки письма (backend/utils.py -> send_reset_email(to_email, reset_link)):
    - использовать API key;
    - указать отправителя: onboarding@resend.dev;
    - указать получателя: to_email - почта, которая указана в БД у админа;
    - в письме передать reset_link - ссылку с токеном восстановления.
