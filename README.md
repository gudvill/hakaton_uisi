# Веб-приложение

> Веб-приложение для проведения мероприятия **«Всероссийский хакатон связи»**, включающее информационный сайт, административную панель и серверную часть с REST API.

---

## Описание

Проект представляет собой веб-приложение для проведения мероприятия **«Всероссийский хакатон связи»**, организуемого Институтом связи.

Система предоставляет участникам доступ к информации о мероприятии и позволяет зарегистрировать команду для участия в хакатоне.

Для администраторов реализована защищённая панель управления, обеспечивающая управление содержимым сайта, регистрациями участников и аналитикой мероприятия.

---

### Информационный сайт

- просмотр информации о мероприятии (программа, кейсы, новости, партнёры, отзывы, фотоальбомы и т.д.);
- регистрация команд и участников на мероприятие.

### Административная панель

- аутентификация администратора по JWT;
- восстановление пароля администратора по электронной почте;
- управление информацией о мероприятии (программой, кейсами, новостями, партнёрами, отзывами, фотоальбомами и т.д.);
- просмотр и управление регистрациями участников;
- просмотр статистики и аналитики мероприятия.

### Интеграции

- **Resend** - отправка писем при восстановлении пароля администратора;
- **Яндекс Метрика** - получение статистики посещаемости сайта.

---

## Архитектура

Система построена по клиент-серверной архитектуре, серверная часть реализована в виде REST API. В состав системы входят: React-приложение (Frontend), FastAPI (Backend), PostgreSQL, Nginx. Каждый компонент развёрнут в отдельном Docker-контейнере с помощью Docker Compose.
