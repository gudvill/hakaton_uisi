1. создать папку рядом с корнем проекта: mkdir -p ~/backups

2. файлы:
- backup.sh;
- restore.sh;

3. выдача прав:
```bash
chmod +x backup.sh
chmod +x restore.sh
```

4. запуск:
- создание бэкапа:
```bash
docker-compose up -d
./backup.sh
```
- восстановление из бэкапа:
```bash
docker-compose up -d
./restore.sh
```

5. восстановление:
- если папка backend/media уже существует, то рядом создастся новая;
- после запуска скрипта: создастся БД hakaton_db, восстановятся все таблицы, данные, последовательности (id), индексы, связи (FK), медиафайлы.

6. автоматический ежедневный бэкап в 03:00
- открыть cron:
```bash
crontab -e
```
- дДобавить:
```sh
0 3 * * * /home/user/project/backup.sh >> /home/user/backup.log 2>&1
```
