1. файлы:
- backup.sh;
- restore.sh;

```bash
# 1. выдача прав
chmod +x backup.sh
chmod +x restore.sh

# 2. создание бэкапа
docker-compose up -d
./backup.sh

# 3. восстановление из бэкапа
docker-compose up -d
./restore.sh
```

2. автоматический ежедневный бэкап в 03:00
```bash
# открыть cron
crontab -e

# добавить
0 3 * * * /root/hakaton_uisi/backup.sh >> /root/backup.log 2>&1
```

3. по бэкапу:
- бэкап хранится в папке backups рядом с корнем проекта;
- копируются медиа (папка backend/media) и БД (таблицы, данные, последовательности (id), индексы, связи (FK));
- если папка backend/media уже существует, то рядом создастся новая.
